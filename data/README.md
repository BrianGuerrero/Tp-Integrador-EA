# Datos

`diabetic_data.csv` — *Diabetes 130-US Hospitals for Years 1999–2008*, UCI Machine Learning Repository (id 296),
https://archive.ics.uci.edu/dataset/296 (licencia CC BY 4.0). Strack et al. (2014).

Si el archivo no está, `tpi.data.load_raw()` lo descarga automáticamente con `ucimlrepo`, o bien:

```bash
python data/download_data.py
```
